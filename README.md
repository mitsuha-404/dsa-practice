## 💡 How to Run the Code
Since this repository contains separate daily practice snippets compiled into single files, follow these steps to execute a specific exercise:

1. Open the target `.cpp` file (e.g., `DAY 1.cpp`).
2. **Uncomment** the specific program block you want to run.
3. **Comment out** all other program blocks in the file to prevent conflicts.
4. Save the file (`Ctrl + S`).
5. Run the standard compilation commands in your terminal:

```bash
# Compile the file using g++
g++ "DAY 1.cpp" -o program

# Run the executable
./program
```
